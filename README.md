# Cloister 🫥

A `cloistered` text editor written in Rust. Offline first, forever. Just you and your files.

## Features

- Multi-tabs, multi-platform, thanks to [egui](https://github.com/emilk/egui)
- No tracking
- No ads
- No spyware
- No data collection
- No strings attached
- No random/weird dependencies
- No invasive permissions
- No forced updates
- NO BLOAT

## Work in progress

I made this wee tool for myself, but I'm sure it will be useful to someone else.
